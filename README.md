# Arafat Hossain — Portfolio Website

Premium multi-page portfolio for **Arafat Hossain** — creative designer & digital project enthusiast from Feni, Bangladesh.

## 🚀 Getting Started Locally

1. পুরো `arafat-portfolio` ফোল্ডার ডাউনলোড / ক্লোন করো।
2. `index.html` ফাইলটা ব্রাউজারে ডাবল-ক্লিক করে ওপেন করো।
   *(অথবা `python3 -m http.server 8000` চালিয়ে `http://localhost:8000` এ যাও)*
